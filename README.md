# 🛡️ Guardian Stack

### AI-Powered Family Protection & Digital Insurance Advisory Platform

Guardian Stack is an intelligent platform designed to help individuals and families plan their financial protection, understand life insurance needs, manage insurance documents, and prepare for emergencies through a unified digital experience.

## 🚀 Key Features

- **Guardian Pulse:** Family protection dashboard for monitoring essential protection information.
- **Life Insurance Needs Finder:** Estimates insurance coverage requirements and identifies potential coverage gaps.
- **AI Digital Advisor:** Helps users understand insurance concepts and explore suitable planning options.
- **Policy Lab:** Explore coverage amounts, policy tenure, premium frequency, and different financial scenarios.
- **Digital Insurance Vault:** Organize and manage insurance documents digitally.
- **Medical Passport:** Keep essential medical information accessible.
- **Premium Reminders:** Track upcoming premiums and payment evidence.
- **Nominee Management:** Organize important nominee information.
- **Emergency SOS:** Access emergency assistance features and hospital discovery.
- **Financial Scenario Simulator:** Explore how changing financial circumstances can affect protection needs.
- **Advisory Reports:** Generate printable insurance planning reports.

## 💡 Problem Statement

Insurance planning can be confusing, fragmented, and difficult to manage. Families may struggle to estimate adequate life coverage, track policies, organize critical documents, and prepare for unexpected emergencies.

Guardian Stack aims to bring these essential capabilities together in one accessible platform.

## 🎯 Our Solution

Guardian Stack combines insurance needs analysis, AI-assisted guidance, family protection tools, document management, and emergency support in a single application. It helps users better understand their financial protection needs and make more informed decisions.

## ⚙️ Getting Started

### Prerequisites

- Node.js and npm
- Git
- A Google Gemini API key, if AI features require it

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd guardian-stack
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Configure the required environment variables using the project's environment configuration and `.env.example`, if provided.

5. Start the development server using the command configured in `package.json`, commonly:

   ```bash
   npm run dev
   ```

6. Open the local URL displayed in your terminal.

> **Note:** Verify the repository's actual scripts and environment variable names before running these commands. Never commit API keys, passwords, or other secrets.
